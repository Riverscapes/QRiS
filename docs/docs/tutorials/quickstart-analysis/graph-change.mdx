# Step 5: Graph Change Through Time

**Time: ~3 minutes**

Finish this QRiS workflow by turning the values you calculated into a simple graph.

## Open the Analysis Summary

Click the graph icon in the top right corner of the Analysis window to open the **Analysis Summary** from your **Quickstart Analysis**.

Then choose:

| Setting | Choose |
| --- | --- |
| **Analysis** | `Quickstart Analysis` |
| **Analysis Type** | `Metric over Time` |
| **Metric** | `Dam Density` |
| **Sample Frame Feature** | `2` |


You should now see a simple comparison between the two monitoring events.



## Read the graph

The graph shows Dam Density in the same sample frame at two different points in time.

## What to know

You used QRiS to complete a basic analysis workflow:
- observations through time (DCEs),
- same measurement area (sample frame),
- same metric,
- comparison.

This is the core idea behind analysis in QRiS.
