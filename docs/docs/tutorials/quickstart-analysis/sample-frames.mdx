# Step 3: Explore Sample Frames

**Time: ~2 minutes**

You have observations through time as data capture events. Now QRiS needs to know where to summarize them.

## Add the sample frames

In the QRiS Project Explorer:
1. Expand the project **Inputs**.
2. Find the sample frame named **SF**.
3. Right-click **SF** → **Add to Map**.

You should see three sample-frame polygons dividing the Bailey Flat riverscape.


## What to know

A **sample frame** is the area within which QRiS calculates metrics. Sample frames let you compare one part of a riverscape with another, or compare the same area through time.

For this quickstart, the three sample frames are already built. You will use them as-is.

You have:

- **DCEs** = observations through time
- **Sample frames** = where QRiS will measure them

Next, you'll tell QRiS **what to calculate**.
