# Step 2: Explore Data Capture Events

**Time: ~3 minutes**

Bailey Flat contains repeated monitoring observations of the same riverscape. QRiS stores each set of observations as a **Data Capture Event**, or **DCE**.

When we add a DCE, the map will zoom to the project extent that the layer encompasses.

## Add the pre-project observations

In the QRiS Project Explorer:

1. Expand **Data Capture Events**.
2. Expand **October 2021 Pre Project**.
3. Find **Structural Elements**.
4. Right-click **Structural Elements** → **Add to Map**.

## Add the implementation observations

Now repeat the same action for the next DCE:
1. Expand **November 2021 Implementation**.
2. Find **Structural Elements**.
3. Right-click the point-based **Structural Elements** → **Add to Map**. (Note: You will see two Structural Elements layers in the November 2021 Implementation DCE. We will use the point-based one, represented by a point icon.)
4. Toggle the two Structural Elements layers on and off in the QGIS Layers panel.


## What to know

Each **Data Capture Event** stores observations representing a riverscape at a particular point in time. Bailey Flat contains DCEs from multiple years and multiple monitoring events, so the same site can be compared through time.

You're looking at structural elements from two different DCEs. You should see many more structural elements in the November 2021 Implementation than in October 2021 Pre Project.
