# Step 1: Open Bailey Flat

**Time: ~2 minutes**

Start with the completed Bailey Flat project so you can explore QRiS before building anything from scratch.

## Open the project

1. Open **QGIS**.
2. On the QRiS toolbar, select **Project** -> **Open QRiS Project**.
3. Navigate to the Bailey Flat folder you extracted.
4. Select **qris.gpkg** and click **Open**.

The **BaileyFlat_0323** project will appear in the QRiS Project Explorer.



:::tip
You should see a zoomed out basemap of the world. We'll zoom in to the project area in our next step.
:::

## What to know

A **QRiS project** keeps the geospatial pieces of a riverscape project together. Bailey Flat already includes project inputs, monitoring events, designs, as-builts, sample frames, and analyses.

You are going to use those existing pieces to see how QRiS turns monitoring observations into comparable metrics.
