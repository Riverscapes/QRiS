# QRiS Quickstart: Analysis - Compare a Riverscape Through Time

**About 15 minutes | Beginner | No GIS analysis experience required**

In this quickstart, you will explore a real restoration monitoring project on the North Fork Sprague River in Oregon. You will compare observations collected through time, create a simple analysis, calculate a riverscape metric, and graph how that metric changes.

By the end, you'll have used a core QRiS workflow for analysis: Data Capture Events &rarr; Sample Frames &rarr; Metrics &rarr; Analysis.

## Before You Begin

Set up these items before starting the 15-minute tutorial:
1. Install [QGIS and the latest QRiS plugin](/download).
2. Open the [Bailey Flat collection in the Riverscapes Data Exchange](https://data.riverscapes.net/c/8df94290-1c69-4e1f-ab04-b31f1b47e83d/).
3. Download **Bailey Flat without Imagery**
4. Extract the downloaded zip file to an easy-to-find folder on your computer.
